16Spiralë 7-ngjyrëshe

Spiralë katrore me 7 ngjyra që ndërrohen.

🐍 Kodi Python origjinalProject (EX) 16.py
import turtle 
a=turtle.Turtle()
screen = turtle.Screen()
screen.bgcolor('black')
col = ('white','orange','red','yellow','green','blue','cyan')
a.speed(80)

for i in range (200):
    a.forward(i*4)
    a.right(91)
    a.color(col[i%7])
for b in range(3):
        a.forward(i*4)
        a.right(91)
for c in range(2):
            a.forward(i*4)
            a.right(91)
