13Spiralë vijash ylberi

Një vijë e vetme spirale me ngjyra ylberi.

🐍 Kodi Python origjinalProject (EX) 13.py
import turtle
import colorsys
t = turtle.Turtle()
s = turtle.Screen()
s.bgcolor('black')
t.speed(0)
n = 80
h = 0
for i in range (302):
    c = colorsys.hsv_to_rgb(h , 1 ,0.8)
    h+= 1/n
    t.color(c)
    t.left(154)
    t.forward(i)
    #turtle.done
    turtle.exitonclick
